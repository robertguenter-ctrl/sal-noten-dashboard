SAL Noten-Dashboard installieren

Auf dem Handy funktioniert Ziehen oft nicht. Am besten: URL kopieren, dann ein Lesezeichen anlegen und die Adresse ersetzen.

Lade Dashboard-Skript…

Anleitung für dein Gerät

  1. Oben auf Bookmarklet-URL kopieren tippen.
  2. In Safari: Teilen-Symbol → Lesezeichen (irgendeine Seite speichern).
  3. Lesezeichen öffnen → Bearbeiten → dieses Lesezeichen wählen.
  4. Feld Adresse / URL komplett löschen und die kopierte URL einfügen.
  5. Namen z. B. «SAL Noten» setzen und speichern.
  6. Auf der SAL-Seite «Aktuelle Noten» das Lesezeichen antippen.
  1. Oben auf Bookmarklet-URL kopieren tippen.
  2. Stern / Menü → Lesezeichen für diese Seite setzen.
  3. Lesezeichen-Manager öffnen → Eintrag bearbeiten.
  4. URL komplett durch die kopierte javascript:…-Adresse ersetzen.
  5. Auf der SAL-Seite «Aktuelle Noten» das Lesezeichen antippen.
