SAL Noten-Dashboard installieren

Das Portal portal.sbl.ch blockiert oft das Nachladen externer Skripte (CSP). Deshalb muss das Bookmarklet den Code inline enthalten.

  1. Lesezeichen-Leiste in Chrome einblenden (Cmd+Shift+B).
  2. Den blauen Button unten in die Lesezeichen-Leiste ziehen.
  3. Auf der SAL-Seite «Aktuelle Noten» das Lesezeichen anklicken.

Lade Dashboard-Skript…

📑 SAL Noten-Dashboard

Nicht in die Adresszeile einfügen — Chrome macht daraus eine Google-Suche. Nur als Lesezeichen speichern und auf der SAL-Seite anklicken.
